# Легенда

ИИ-агент шифрует свои исходящие сообщения классическим (и слабым) шифром XOR с повторяющимся ключом. Секретный ключ из K байтов выбирается один раз. Чтобы зашифровать открытый текст сообщения P (последовательность байтов), каждый байт открытого текста подвергается операции XOR с байтом ключа, который циклически перебирается по ключу:

cipher[i] = plain[i] XOR key[i mod K]
Затем шифротекст передаётся в виде шестнадцатеричной строки в нижнем регистре (по две шестнадцатеричные цифры на байт).

У протокола есть фатальный изъян: каждое сообщение начинается с одной и той же фиксированной строки рукопожатия H (баннер или заголовок протокола). Вы знаете H, и вы знаете длину ключа K (при K <= len(H)). Это классическая атака с известным открытым текстом: первые K байтов открытого текста известны, чего достаточно для восстановления всего ключа.

Вы перехватили M сообщений, все зашифрованы одним и тем же ключом и все начинаются с H. Восстановите ключ и расшифруйте каждое сообщение.


# Условие

Дана длина ключа K, известный префикс открытого текста H и M шифротекстов в шестнадцатеричной кодировке. Восстановите K-байтовый ключ и выведите полный расшифрованный открытый текст каждого сообщения.


# Формат ввода

* Первая строка содержит два целых числа K и M (1 <= K <= 64, 1 <= M <= 100).
* Вторая строка содержит известную строку рукопожатия H, заданную дословно (она может содержать пробелы) с K <= len(H) <= 1000.
* Каждая из следующих M строк содержит один шифротекст в виде шестнадцатеричной строки в нижнем регистре чётной длины. Каждое сообщение имеет размер от K до 100000 байтов (до 200000 шестнадцатеричных символов).


# Формат вывода

Выведите M строк. Строка t — это расшифрованный открытый текст t-го шифротекста, выведенный как обычный текст. Гарантируется, что каждый открытый текст состоит из печатаемых символов ASCII (байты 32..126), возможно, включая пробелы.
