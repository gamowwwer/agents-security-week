# Легенда

ИИ-платформа выдаёт API-токены своим агентам. Чтобы выявлять опечатки и явно поддельные токены до выполнения любого дорогостоящего поиска, каждый токен заканчивается контрольной цифрой, вычисленной с помощью алгоритма Луна (та же контрольная сумма, что используется в номерах кредитных карт).

Токен — это строка десятичных цифр, возможно записанная с разделителями - или пробелами для удобочитаемости (например, 4539-1488-0343-6467). Разделители не несут смысла и должны игнорироваться. После удаления разделителей токен должен состоять только из цифр.

Шлюз безопасности хочет быстро отклонять любой токен, не прошедший контрольную сумму.

# Алгоритм Луна

Дана строка цифр d_1 d_2 ... d_n (слева направо), проверка выполняется так:

Начиная с самой правой цифры и двигаясь влево, удваивайте значение каждой второй цифры (то есть цифры на позициях 2-я справа, 4-я справа и так далее).
Если при удвоении цифры получается число больше 9, вычтите из него 9 (что эквивалентно сложению двух десятичных цифр произведения).
Просуммируйте все получившиеся значения (удвоенные-и-скорректированные цифры вместе с нетронутыми цифрами).
Токен действителен тогда и только тогда, когда эта сумма кратна 10.

# Условие

Вам дано M кандидатов-токенов. Для каждого токена:

удалите все символы-разделители - и пробелы;
если оставшееся пусто или содержит любой нецифровой символ, токен INVALID;
иначе примените проверку Луна и выведите VALID, если контрольная сумма проходит, и INVALID в противном случае.


# Формат ввода

Первая строка содержит одно целое число M -- количество токенов (1 <= M <= 100000).
Каждая из следующих M строк содержит один кандидат-токен. Строка токена имеет длину от 1 до 100 символов и может содержать цифры, - и пробелы. Токены заданы дословно (токен никогда не имеет ведущего/завершающего содержимого, кроме описанных разделителей).


# Формат вывода

Выведите M строк. Строка t -- это VALID или INVALID для t-го токена.
