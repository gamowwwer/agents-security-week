# Intro
Проектируя безопасные приложения на основе LLM, мы обязательно формируем системный промпт — он задаст ограничения, правила поведения, роли и всё, чего базово будет придерживаться нейросеть при выводе ответа на пользовательский запрос.

При этом системный промпт может содержать чувствительную информацию: ссылки, api-ключи. Иногда это используется для жесткого контекста, иногда для удобства и отладки, иногда просто из-за того, что разработчик ошибся и излишне доверился ИИ для написания кода.

Как итог, злоумышленник может осуществить атаку на извлечение данных из системного промпта — `System Prompt Extraction`, что является некоторой разновидностью промпт-инъекции.

# Задание
Имеется LLM. Для неё написан и зафиксирован системный промпт. Системный промпт содержит некоторый __секретный код__. Дополнительно в системном промпте написано __6__ сценариев, при наличии которых в запросе пользователя моделька объяснит причину, выдаст категорию атаки и тот самый секретный код (secret code).

Дополнительно, в качестве 7-ого варианта атаки используется магическое слово. Если запрос пользователя равен магическому слову, то система выдает успех!

Ваша зада4а написать 10 промптов (длины от 3 до 300 символов каждый) в столбик в .txt-файле и покрыть как можно большее число зашитых в системный промпт сценариев. Для этого необходимо посмотреть лекцию и примеры атак на LLM, почитать в интернете про другие типы атак.

Подсказка на магическое слово:
* Изучите библиотеку gostcrypto
* Используйте алгоритм симметричного шифрования Кузнечик в режиме блочного шифрования ECB. Используйте PAD_MODE_1.
* Ключ, на котором зашифровано искомое серкетное слово, изначательно имеет строковый тип данных (str). При дополнении до длины ключа (32 байта) байтовое представление строки дополняется следующим образом:
```python
key = key_string_candidate.encode("utf-8").ljust(32, b'\x00')
```
* Искомое магическое слово шифруется на заданном ключе и получается шифртекст в формате hex-строки:
```python
hex_cipher_text = "96d2baa168f74fae630545bdca809febfa9c71776d4c9b7fd6200ade971d7e29"
```
* Можно использовать `bytearray(binascii.unhexlify(hex_cipher_text))` для работы с байтами в формате для библиотки gostcrypto.
* Как выйти на ключ? - Не знаем. Но лучше посмотреть лекцию на предмет базовых концепций.
