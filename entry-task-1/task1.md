# Легенда

Валентина и Дмитрий обмениваются секретными сообщениями. Каждое сообщение, которое они отправляют друг другу, содержит одно число -- настоящую информацию, которой они хотят поделиться.

Чтобы не дать перехватчику прочитать настоящее число, они заранее договорились об одном секретном простом числе P. Перед отправкой сообщения отправитель не передаёт настоящее число x напрямую. Вместо этого он передаёт замаскированное значение

m = x * P

Таким образом, каждое перехваченное сообщение -- это произведение общего секретного простого числа P и некоторого настоящего числа x (настоящие числа различаются от сообщения к сообщению и никогда не раскрываются).

Вы -- перехватчик. Вы захватили несколько таких замаскированных сообщений. Ваша задача — восстановить секретное простое число P.

# Условие

Даны n перехваченных сообщений m_1, m_2, ..., m_n, где каждое

m_i = x_i * P
для некоторого положительного целого x_i (вам неизвестного) и одного и того же секретного простого числа P, восстановите P.

Гарантируется, что:

P — простое число,
каждое сообщение делится на P,
числа x_i, взятые вместе, не имеют общего простого множителя

# Ограничения

Ограничения
2 <= n <= 100
2 <= m_i <= 10^18
P -- простое число, и 2 <= P <= 10^18.

# Формат ввода

Первая строка содержит одно целое число n -- количество перехваченных сообщений (2 <= n <= 100).
Вторая строка содержит n целых чисел, разделённых пробелами, m_1 m_2 ... m_n -- перехваченные сообщения (2 <= m_i <= 10^18).


# Формат вывода

Выведите одно целое число -- секретное простое число P.
